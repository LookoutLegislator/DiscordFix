> Антивирус может отреагировать на WinDivert.  
> WinDivert перехватывает и фильтрует сетевой трафик и нужен для работы zapret.
> Этот инструмент могут применять как безопасные, так и вредоносные программы, однако сам WinDivert вирусом не является.
>
> **Фрагмент из [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) проекта [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Часть антивирусов относит компоненты WinDivert к программам повышенного риска или хакерским инструментам. В результате файл удаляется и перемещается в карантин. Название обнаружения обычно содержит `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`
>
> Добавьте каталог с zapret в исключения антивируса или отключите обнаружение PUA — потенциально нежелательных приложений. Например, в Kaspersky существует параметр "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы понимаете, как настраивать исключения, предпочтительно добавить каталог в исключения. В противном случае безопаснее отключить обнаружение PUA.

## ⚙️Использование

1. Сначала включите безопасный DNS (Secure DNS)
    * В Chrome активируйте пункт "Использовать безопасный DNS" и выберите DNS-провайдера, отличного от "Поставщик по умолчанию"
    * В Firefox откройте "DNS через HTTPS", установите режим "Персональный", выберите "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован
    * В Windows 11 Secure DNS можно включить непосредственно в настройках системы — инструкция доступна [здесь](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 этот вариант рекомендуется
    * На роутерах Keenetic включите параметр "Транзит запросов". Если его отключить, Secure DNS на компьютере может работать некорректно

2. Загрузите zip- или rar-архив с [последнего релиза](https://github.com/LookoutLegislator/zapret-discord-youtube/releases/latest)

3. Откройте свойства загруженного архива и включите флажок "Разблокировать". При распаковке через 7-Zip или PeaZip этот пункт можно не выполнять

4. Извлеките файлы в каталог, в пути к которому нет кириллицы и специальных символов

5. Запустите подходящий файл
    * Для поиска рабочей стратегии откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Чтобы включить запуск вместе с системой, выберите **`service.bat`** -> `Install Service` -> *подходящую стратегию*

## ℹ️Кратко о файлах и командах

- [**`general.bat ...`**](./general.bat) — ручной запуск стратегии

  Такой запуск удобен для проверки разных вариантов обхода. Результат зависит от множества условий, поэтому **перебирайте стратегии (ALT, FAKE и другие), пока не найдёте подходящую именно для вашей системы**

- [**`service.bat`**](./service.bat) — установка автозапуска и дополнительные операции:
  - <ins>**`Install Service`** — добавление выбранной стратегии в автозапуск через services.msc</ins>
  - **`Remove Services`** — удаление стратегии и WinDivert из служб
  - **`Check Status`** — просмотр состояния обхода и служб, включая автозапущенную стратегию и WinDivert
  - **`Game Filter`** — включение или отключение обхода для игр и других сервисов, работающих с UDP и TCP на портах выше 1023.  
  **После изменения настройки стратегию нужно перезапустить.**  
  В скобках отображается текущее состояние: включено или выключено.
  - **`IPSet Filter`** — выбор режима фильтрации ресурсов из `ipset-all.txt`.  
  Опция полезна во время диагностики, когда ресурс не открывается с zapret, хотя без него работает.  
  В скобках показывается текущий режим:
    - `none` — IP-адреса не проверяются
    - `loaded` — проверяется совпадение IP со списком
    - `any` — под фильтр попадает любой IP  
  - **`Auto-Update Check`** — включение или отключение автоматической проверки обновлений
  - **`Replace active fakes`** — замена используемого фейка на другой файл из каталога `bin`
  - **`Update IPSet List`** — загрузка актуального `ipset-all.txt` из репозитория
  - **`Update Hosts File`** — обновление hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовому чату Discord**</ins>
  - **`Check for Updates`** — ручная проверка наличия обновлений
  - **`Run Diagnostics`** — поиск распространённых причин неисправности zapret.  
  В конце диагностики можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает вернуть неожиданно прекратившуюся работу
  - **`Run Tests`** — запуск проверки стратегий:
    - `Standard tests` — тестирование сайтов из `utils/targets.txt`
    - `DPI checkers` — проверка DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️Распространенные вопросы и проблемы

### После запуска `general*` ничего не открывается

- При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe. Его можно заметить в панели задач.  
Если этого не произошло, ознакомьтесь с [#522](https://github.com/LookoutLegislator/zapret-discord-youtube/issues/522)

### Не удалось подобрать стратегию
- Запустите командную строку с правами администратора
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер

### Не открывается Telegram в браузере
Откройте **`service.bat`** и выберите **`Update hosts file`**. Если текущая запись hosts устарела, программа предложит обновить её вручную:  
  - Скопируйте весь текст из открытого блокнота
  - Откройте файл `hosts` в созданной папке через текстовый редактор, запущенный от имени администратора
  - Вставьте скопированный текст в конец файла `hosts` или замените ранее добавленные аналогичные строки
  - Сохраните изменения и проверьте соединение. Если проблема останется, убедитесь, что файл hosts действительно был сохранён.

#### Работа не гарантируется. Если этот способ не помог, используйте [Desktop-версию Telegram](https://github.com/telegramdesktop/tdesktop/releases) вместе с [локальным прокси](https://github.com/LookoutLegislator/tg-ws-proxy) или любым публичным прокси.

### Обход не запускается или перестал работать

> [!IMPORTANT]
> **Рабочие стратегии могут со временем устаревать.**
> Стратегия иногда работает продолжительное время, а затем перестаёт помогать после обнаружения используемого метода.
> Здесь собрано много вариантов обхода. Если готовые стратегии не подходят, создайте новую на основе одной из них и измените её параметры.
> Описание параметров стратегий находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Запустите `service.bat` -> `Run Diagnostics` и проверьте, нет ли ошибок

- Убедитесь, что нужный ресурс присутствует в списках доменов или IP-адресов

- Проверьте другие варианты, включая **`ALT`** и **`FAKE`**

- Выполните полную переустановку по инструкции ниже

- Дополнительная информация: [#765](https://github.com/LookoutLegislator/zapret-discord-youtube/issues/765)

### Как полностью обновить или переустановить проект?
- Сохраните добавленные вами ресурсы и другие необходимые данные
- Перезагрузите устройство
- Выполните `service.bat` -> `Remove Services`
- Затем выберите `service.bat` -> `Run Diagnostics`; устраните найденные ошибки и в конце подтвердите действие клавишей Y
- Удалите старый каталог zapret
- Скачайте свежую версию [со страницы релизов](https://github.com/LookoutLegislator/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`)
- Нажмите правой кнопкой мыши на архиве и откройте свойства. Если в нижней части окна есть флажок разблокировки, включите его, нажмите применить и подтвердите кнопкой ОК
- Распакуйте архив в новую папку в корне диска, используя путь без пробелов и специальных символов
- Запускайте разные скрипты `general` и проверяйте доступ к ресурсам. Если выбранный вариант не работает, закройте программу через значок замка в панели задач и попробуйте следующую стратегию
- После обнаружения рабочего варианта добавьте его в автозапуск через `service.bat` -> `Install Service`

### Игра или приложение не работает при активном zapret

- В `service.bat` проверьте, что `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит обнаруживает WinDivert

- Используйте инструкцию из https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- Замените `WinDivert.dll` и `WinDivert64.sys` в каталоге [`bin`](./bin) одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### После удаления через [**`service.bat`**](./service.bat) WinDivert всё ещё отображается среди служб

1. Найдите имя службы командой в командной строке Windows. Открыть её можно через Win+R, введя `cmd`:

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование)
- Отключите блокировщик рекламы: известно, что YouTube начал активно противодействовать таким расширениям.
- Переберите остальные стратегии, особенно если раньше сервис открывался.
- Также см. [#251](https://github.com/LookoutLegislator/zapret-discord-youtube/discussions/251)

### Не запускается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что настроен [Secure DNS](#%EF%B8%8Fиспользование)
- Сначала определите стратегию, на которой открывается YouTube, и запустите её
- В `service.bat` откройте `Run Diagnostics` и очистите кэш Discord
- Проверьте, заработало ли приложение после очистки кэша
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно временно пользоваться ей
- Если Discord не открывается и в браузере, снова проверьте все стратегии: YouTube и Discord могут работать на разных вариантах
- См. также [#252](https://github.com/LookoutLegislator/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/LookoutLegislator/tg-ws-proxy)
- Также можно воспользоваться бесплатными MTProto-прокси, доступными в интернете

### Не подключаются игры

Игр много, поэтому проверить и исправить работу каждой из них отдельно невозможно.

Общий порядок действий:
- через `service.bat` обновите ipset и включите `Game Filter`
- если это не помогло, дополнительно включите режим `ipset any`

Учитывайте, что `ipset any` способен нарушить открытие многих сайтов. Не оставляйте этот режим включённым постоянно. Лучше определить все IP-адреса, которые использует игра, и добавить их в `ipset-all.txt`

Если результата нет, создайте обсуждение в разделе [Discussions](https://github.com/LookoutLegislator/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

## 🗒️Добавление адресов других ресурсов

Список ресурсов для обхода можно настроить вручную. Используйте следующие файлы:
- **`list-general-user.txt`** — домены; поддомены учитываются автоматически
- **`list-exclude-user.txt`** — домены, которые нужно исключить. Например, если IP сети есть в `ipset-all.txt`, но конкретный домен этой сети фильтровать не требуется
- **`ipset-all.txt`** — IP-адреса и подсети
- **`ipset-exclude-user.txt`** — IP-адреса и подсети, которые следует исключить
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`
